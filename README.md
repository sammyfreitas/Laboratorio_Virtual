# 💻 Laboratório Virtual — Rufus, BIOS e UEFI

Simulador educacional desenvolvido em **HTML, CSS e JavaScript** para aulas de Sistemas Operacionais, boot, mídias inicializáveis, BIOS Legacy e UEFI.

## 🌐 Acesse online

### 👉 [Abrir Laboratório Virtual](https://sammyfreitas.github.io/Laboratorio_Virtual)

> [!IMPORTANT]
> Este é um simulador educacional. Nenhuma configuração real do computador, BIOS, UEFI, disco ou pendrive é modificada.

## 🧪 Laboratórios

| Laboratório | Conteúdos |
|---|---|
| 💿 **Rufus** | ISO, GPT, MBR, FAT32, NTFS e mídia inicializável |
| ⌨️ **BIOS Legacy** | CMOS, chipset, periféricos, energia, hardware e boot |
| ⚙️ **UEFI** | Main, Advanced, Boot, Security, Secure Boot, TPM e Save & Exit |

O Rufus possui um seletor fictício de arquivos ISO de Linux Mint, Ubuntu, Fedora, Red Hat Enterprise Linux, Windows 7, Windows 10 e Windows 11. BIOS e UEFI permitem navegar e alterar diversas opções fictícias para fins didáticos.

## 🌗 Tema claro e escuro

Use o botão superior para alternar o tema. A escolha fica salva no navegador.

## 🎓 Sugestão de atividade

Peça ao aluno para preparar uma mídia fictícia no Rufus, abrir a BIOS ou UEFI, colocar o dispositivo USB como primeira opção de boot, salvar e explicar o que aconteceria após a reinicialização.

## 🚀 Executar

```bash
git clone https://github.com/sammyfreitas/Laboratorio_Virtual.git
cd Laboratorio_Virtual
```

Depois abra `index.html`.

## 🔒 Segurança

O projeto não acessa ou modifica BIOS/UEFI reais, discos, partições ou pendrives e não instala sistemas operacionais. Todas as ações são simulações visuais.
